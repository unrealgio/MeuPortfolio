# Meu Portfólio

> Portfólio pessoal desenvolvido para apresentar minha experiência, projetos, habilidades e trajetória como Full Stack Web Developer.

##  Sobre o projeto

Este projeto é meu portfólio pessoal, desenvolvido com foco em uma experiência moderna, responsiva e intuitiva.

O site reúne informações sobre minha trajetória profissional, principais habilidades, projetos desenvolvidos e formas de contato, funcionando como uma apresentação profissional do meu trabalho como desenvolvedor web.

##  Funcionalidades

- Apresentação profissional
- Seção sobre mim
- Tecnologias e habilidades
- Projetos desenvolvidos
- Experiência profissional
- Links para contato e redes profissionais
- Layout responsivo para diferentes dispositivos
- Interface moderna e interativa

##  Tecnologias

- React
- Vite
- JavaScript
- HTML5
- CSS3
